BOSS 求职 AI 助手 · 隐私政策

扩展名称：BOSS 求职 AI 助手
适用版本：0.1.0
最后更新日期：2026-10-22
开发者联系方式：Menpengpeng@users.noreply.github.com

本政策用于向 Microsoft Edge 加载项审核团队与最终用户说明：本扩展收集什么、存储在哪里、会把什么内容发送出去，以及你可以如何删除这些数据。

1. 一句话概述

本扩展是一款辅助求职的浏览器扩展：在你浏览 BOSS直聘 页面时，帮助你分析岗位、评估简历匹配度、生成沟通建议并识别风险信号。所有数据仅保存在你自己的浏览器本机；全部模型请求都由你主动点击触发，并直接发送到你自行配置的模型服务商，不经过开发者的任何服务器。

2. 收集与存储的数据

本扩展仅在本地保存以下数据，且全部由你在使用过程中主动产生：

数据说明
简历文本与 PDF你粘贴的简历文本，或你上传的 PDF 原件（含 PDF 二进制文件）
设置与 API Key服务商选择、Base URL、模型名、temperature、max_tokens、超时、流式开关、脱敏开关，以及你填写的 API Key
分析结果岗位分析、匹配度、打招呼语、聊天建议、公司分析、面试题等结果，以及岗位快照
聊天记录聊天助手生成的建议与你启用的会话上下文（最多最近 20 条消息）
收藏与快评分数你收藏的岗位、多岗位对比数据、列表页岗位快评分数的缓存
本地日志用于排障的环形日志（有容量上限，写入前已脱敏）

以上数据全部保存在你当前这台设备的浏览器本地（chrome.storage.local 与 IndexedDB boss-ai v1），不会上传到任何服务器，也不会在多设备之间同步。

4. 我们不做的事

  • 不包含任何统计、埋点、行为分析或广告 SDK。
  • 不包含任何远程日志上报，不会把数据发回开发者。
  • 不向开发者（或任何第三方）服务器发送任何数据。
  • 不使用远程代码：所有脚本、样式与资源均为扩展包内置的本地产物。
  • 不自动打招呼、不自动回复、不批量采集或抓取页面数据。
  • API Key 仅保存在本机，界面上以脱敏形式显示，且绝不写入日志、错误提示或错误上报。

5. 唯一的外部网络请求

本扩展唯一的外部网络请求是：向你本人在设置页配置的模型服务商域名发起请求。

  • 请求目标就是你选择的那个服务商（例如 OpenAI、Claude、DeepSeek、通义千问、Kimi、智谱，或你自定义的 Base URL）。
  • 请求必须由你点击界面按钮触发（如「分析此岗位」「生成打招呼语」等），扩展不会在后台自动发起。
  • 当你未配置 API Key、或未通过连通性测试时，扩展不会发起任何模型请求。
  • 页面 MutationObserver 只用于监听登录状态与「HR 新消息」，仅更新界面提示，不会因此调用模型。

6. 会发送给你所配置服务商的内容范围

当你主动点击触发某个 AI 功能时，扩展会把你当前操作所依赖的以下内容发送给你配置的服务商：

  • 职位描述（JD）文本：当前岗位的 JD 原文（如无法自动解析，可手动粘贴兜底）。
  • 页面可见的岗位 / 公司信息：从当前页面解析到的岗位名称、公司名称、薪资等可见信息；公司分析结论统一标注「基于页面信息，非权威核实」。
  • 简历内容：
    • 粘贴文本模式：发送前会先在本机脱敏，把手机号、邮箱、微信号、身份证号替换为占位符（形如 [手机号1]）；姓名是否脱敏由「姓名也脱敏」开关决定（默认开启）。发送内容不含上述原文。
    • PDF 模式：详见第 7 节。
  • 聊天消息：最多取最近 20 条会话消息（超长会先摘要）。该模块需要你首次单独确认启用（设置页「聊天模块授权」开关）后才会发送。
  • 可选的 PDF 简历原文：仅在你上传并确认后发送，详见第 7 节。

不会发送的内容：完整的 API Key、你在其他网站上的浏览记录、与你当前操作岗位无关的页面内容。

7. PDF 简历原文发送说明

两种简历来源处理方式不同，请务必知悉：

  • 粘贴文本模式：文本在你本机完成脱敏后再发送（手机号、邮箱、微信号、身份证号已被替换；姓名按开关）。
  • 上传 PDF 模式：扩展不做本地解析、不做本地脱敏。PDF 会被原样保存到本机 IndexedDB，并在你首次上传前单独勾选确认（提示「PDF 将以原文发送，无法本地脱敏」）后，才可能随请求以原文附件形式发送给服务商。
    • 只有当所选服务商支持 PDF 原生输入时（例如 OpenAI、Claude），才会以原文附件发送。
    • 不支持 PDF 的服务商（如 DeepSeek、通义千问、Kimi、智谱、自定义）会返回错误码 UNSUPPORTED_ATTACHMENT，界面提示「当前服务商不支持 PDF 附件」，并引导你改用粘贴简历文本。
    • PDF 校验规则：MIME 必须为 application/pdf、文件头必须为 %PDF、大小不超过 10MB，并计算 SHA-256 用于本地标识。

由于 PDF 中可能包含手机号、邮箱、身份证号等个人信息，请自行确认是否愿意以原文发送给所选服务商。

8. 权限最小化说明

本扩展遵循最小权限原则，扩展清单（manifest）中的权限如下：

  • permissions：仅 storage，用于本地保存配置与缓存。
  • host_permissions：仅 https://www.zhipin.com/*，用于在 BOSS直聘 页面注入界面并解析当前可见页面信息。
  • optional_host_permissions：https://*/*，仅在你配置自定义 API 域名并点击保存 / 测试时，通过 chrome.permissions.request 向你动态申请该域名权限；你拒绝时会提示错误码 NO_PERMISSION 并保持可编辑，不会强行申请。

内容脚本仅在页面加载完成后（document_idle）注入，且仅在 BOSS直聘 域名下运行。

9. API Key 的处理

  • API Key 仅保存在本机 chrome.storage.local 中，仅在发起接口请求时才读取。
  • 界面（含「导出我的数据」）中显示与导出的 Key 均为脱敏形式（例如仅保留前后少数字符）。
  • Key 绝不会写入本地日志，也不会出现在任何错误信息中；错误信息在生成前会统一做密钥脱敏。

10. 如何删除你的数据

你可以随时在本机彻底删除全部数据：

  • 设置页 →「隐私」→「一键清除全部数据」：会清空 chrome.storage.local 中的配置与日志，以及 IndexedDB boss-ai 中的简历（含 PDF 文件）、分析历史、缓存、收藏、对比与会话状态，本地无残留，且不可恢复（清除前会要求你勾选确认）。
  • 你也可以在浏览器扩展管理页卸载本扩展，卸载后浏览器会清除该扩展的全部本地存储。

此外，设置页还提供「导出我的数据」（JSON，不含完整 API Key），以及历史记录页的「导出 Markdown / CSV」，方便你在清除前自行留存。
